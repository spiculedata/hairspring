M1d summary: informational, native macOS darwin/arm64; race cells are labelled 'race detector on macOS'.
Not Hermit. Not the engine. Counts only.
Not comparable with any Hermit count (different host, different -q, no scheduler).

Columns: runs = runs in the cell; viol_runs = runs whose protocol report has the property site false at least
once; falses = the property site's false evaluations, summed over the runs; foreign_next = driver Next calls
made while another query's Scan was in flight (a driver-side overlap counter, not a property result), summed;
nonzero = runs with an unexpected exit status; races = runs whose stderr has a race-detector report;
reports = race-detector reports, summed; status = ran, or for race cells ran-and-clean / ran-and-reported.

Cells: native = the plain build, GOMAXPROCS=2 (gmp2) or the default (gmpdef); race = built with the race
detector; std = the unassisted workload, yield = the assisted control.
